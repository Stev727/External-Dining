总览整体流程

外部人员

扫码进入小程序→ 填报信息→ 自选地点或交管理员分配→ 获得凭证码→ 查询地点 / 路线→ 就餐

内部管理员

钉钉收到就餐通知→ 点链接直达分配→ 分配用餐地点→ 就餐后维护金额

高管（每日定时）

系统定时钉钉推送→ 点链接确认就餐/不就餐→ 变更可取消重选→ 自动统计

外部人员一、填报订餐

扫码进入小程序「外部人员就餐」，按提示填写并提交。

  1. 选择用餐日期：默认今天，可选未来 7 天内的日期。
  2. 选择餐别：早餐 / 午餐 / 晚餐，支持多选（如同时勾选午餐和晚餐）。
  3. 填写个人信息：姓名、联系电话（可一键授权自动填充）、工作单位。
  4. 选择到访区域：提交后系统会自动通知该区域的接待管理员。
  5. 填写被访问人：即本次来访对接的公司内部同事姓名。
  6. 选择被访部门：从下拉列表中选择（下拉选项由后台统一维护）。
  7. 选择就餐地点：如果内部已安排好就餐地点，可直接从列表中选择，提交即自动分配，无需等待；如果不确定，选择「不确定，由管理员分配」，由接待管理员后续分配。
  8. 填写人数：默认 1 人，按实际就餐人数填写；如有需要可补充备注。
  9. 提交：提交成功后系统生成一个 6 位查询凭证码，请截图或记下保存。
提交规则：同一手机号、同一天、同一餐别只能提交一次；不同餐别可继续提交（如中午提交过午餐，还可以再提交晚餐）。自选了地点的订单显示「已分配（自选）」，无需等待管理员操作。

外部人员二、查询分配结果与进入指引

  1. 进入小程序「订餐查询」页面。
  2. 可通过「我的订单」直接查看，或输入 6 位凭证码 查询（换手机也能查）。
  3. 地点确定后（自选或管理员分配），即可看到：用餐地点名称、地点实拍图片、如何进入的文字指引。
  4. 按指引前往指定食堂就餐即可。
显示「待分配」属正常状态，请管理员分配后再来查询。小程序订阅消息开通后，分配结果还会自动推送到微信，无需手动查询。

内部管理员三、接收钉钉通知

外部人员提交订单后，钉钉机器人会以单独会话的形式，将订单推送给该区域的全部接待成员。自选地点的订单同样会通知，但无需你再分配。

通知样式示例（待分配）
【外部人员就餐通知 · 区域A】
· 用餐日期：2026-11-10（周二）
· 餐别：午餐
· 申请人：张三
· 联系人电话：19900000001
· 被访部门：信息中心
· 访问人：李四
· 人数：3
· 地点：待管理员分配
👉 点此分配（点击直达管理端并自动定位该订单）
通知样式示例（外部人员自选了地点）
· 地点：二食堂（外部人员自选，无需分配）
点击通知里的「点此分配」链接，系统自动登录跳转并高亮定位到这条订单，直接分配即可，不用手动翻找。

内部管理员四、登录管理端并分配地点

  1. 浏览器打开管理端：http://10.1.4.23:48081/admin/（正式环境地址以内部通知为准），输入系统账号和密码登录（账号由管理员统一创建，见「账号与设置」）。
  2. 左侧菜单进入「订餐记录」，可按日期 / 状态筛选，支持分页浏览；也可直接点钉钉通知里的分配链接直达。
  3. 勾选待分配订单 → 选择右上角「分配到：××」→ 点「批量分配选中」，支持一次分配多单。
  4. 分配成功后：外部人员即可在查询页看到地点和进入指引；系统自动按「人数 × 地点单价」记录预计金额。
后续调整：点击人数可直接修改（预计金额自动重算）；「取消分配」回滚金额并回到待分配；「拒绝」用于特殊情况，需填写原因；「维护真实」登记实际消费金额。

内部管理员五、日常管理与统计

  1. 运营看板：图形化展示就餐总人数、总部预计/真实金额，月度就餐人数柱状图（近 12 个月）、被访部门金额横条图；可切换 本月 / 今年 / 全部 范围。
  2. 真实金额：就餐完成后，在订餐记录点「维护真实」登记实际消费金额，与预计金额对比；分页导出，账目清晰。
  3. 地点与路线：维护各食堂的人均单价（可改价，改价只影响之后的分配）、地点图片与「如何进入」说明（说明文字输入后自动保存）。
  4. 区域与成员：维护到访区域及各区域的钉钉通知成员（按手机号匹配）。
  5. 被访部门：维护小程序填报页的下拉选项。
  6. 导出：按当前筛选条件导出 Excel，含金额列，可直接用于费用核对。

高管就餐六、每日定时确认与自动统计

系统按餐别在设定时间点自动钉钉推送确认消息给高管，高管点链接一键确认，结果自动生成订单计入统计，无需人工登记。

到点自动推送→ 高管点链接（免登录）→ 确认就餐（填人数）/ 不就餐→ 有变更可取消重选→ 自动计入统计

管理员侧（管理端 →「高管就餐」菜单）

  1. 维护高管名单：添加姓名、钉钉手机号、部门、默认餐别（午餐/晚餐/早餐/午+晚），支持停用与删除。
  2. 设置推送时间：早餐 / 午餐 / 晚餐各一个推送时间点（如午餐 11:00、晚餐 17:00），到点只推对应餐别；留空表示不推送该餐。
  3. 设置取消截止：早餐 / 午餐 / 晚餐各一个截止时间（如午餐 11:30）。高管确认就餐后，超过当天该餐别截止时间就不能再取消，确认页会提示联系管理员。
  4. 设置工作日历：默认周一~周六上班；点击日期可切换上班/休息，支持翻月设置任意月份的公司节假日（与法定节假日不一致也能设）。非工作日不推送。
  5. 查看明日确认状态：一屏看到每位高管各餐别的确认情况（就餐人数 / 不就餐 / 未确认）与推送结果。

高管侧（钉钉）

推送消息示例
【午餐就餐确认 · 张总】
· 就餐日期：2026-11-11（周三）
· 餐别：午餐
· 地点：高管餐厅
👉 点此确认是否就餐
  1. 点击推送里的链接，打开确认页（免登录，无需输账号密码）。
  2. 尚未确认时：显示「确认就餐」（绿色）和「不就餐」（红色）两个按钮，确认就餐需填写人数。
  3. 已确认就餐后：只显示「取消就餐（11:30 前可取消）」按钮；行程有变时点击取消，即可重新选择。
  4. 已确认不就餐后：只显示「确认就餐」按钮，临时要来可直接改回。
  5. 超过取消截止时间后，取消按钮消失，页面提示「已超过取消截止时间，如需变更请联系管理员」。
确认就餐后系统自动生成订单（地点、餐别、人数、金额快照齐全），直接进入订餐统计与导出，全程无需人工录入。各餐别独立确认，互不影响；若配置了「午+晚」，午餐和晚餐会分别推送、分别确认。

系统管理七、账号与设置（管理员）

  1. 用户管理：管理员在「用户管理」菜单创建系统账号（用户名 + 密码 + 角色），支持重置密码、停用、删除。操作员只能进行日常分配、改人数、维护金额、查看看板与导出；管理员额外可维护地点/区域/部门/账号及全部设置。
  2. 系统设置：钉钉应用的 AppKey / AppSecret / AgentId 均可在界面上直接配置，保存后立即生效（已保存的密钥以掩码显示，保持不变即不修改）。
  3. 管理端地址：配置钉钉通知里「点此分配」链接的跳转地址，正式上线时填写公网 HTTPS 地址。
推广说明：换一家公司使用时，只需由管理员在「系统设置」里替换为该公司的钉钉应用信息，再配置地点/区域/部门即可，无需改代码。

附录常见问题

问题说明
提交后提示「已提交过」？同手机号同日同餐别不可重复提交。如需改餐别请修改为新餐别重新提交，或联系接待人。
查询页一直显示「待分配」？填报时选了「不确定，由管理员分配」，管理员尚未分配地点，请联系被访部门催办；下次填报可直接自选地点。
凭证码丢了怎么办？同一微信进入「我的订单」可直接查看；换手机可联系接待人代查。
钉钉没收到通知？确认你已被管理员加入对应「区域成员」列表，且钉钉资料中的手机号与管理端登记一致。
人数填错了？管理员可在订餐记录中点击人数直接修改，预计金额自动重算。
高管确认页找不到「取消就餐」按钮？已超过当天该餐别的取消截止时间（如午餐 11:30），系统锁定不允许自行取消，请联系管理员处理。
高管到点没收到推送？检查：① 明天是否为工作日（工作日历）；② 该高管默认餐别是否包含此餐；③ 高管是否已停用；④ 钉钉手机号是否正确。
高管确认了午餐，晚餐还要再确认吗？要。各餐别独立推送、独立确认。若名单里配了「午+晚」，两个餐别都会推送。
忘记管理端密码？联系管理员在「用户管理」中为你重置密码。
