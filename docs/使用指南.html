外部人员就餐系统 · 使用指南

外部人员扫码填报 ｜ 管理员分配地点 ｜ 钉钉机器人实时通知

总览整体流程

外部人员

扫码进入小程序→ 填报信息→ 获得凭证码→ 查询地点 / 路线→ 就餐

内部管理员

钉钉收到就餐通知→ 登录管理端→ 分配用餐地点→ 就餐后维护金额

外部人员一、填报订餐

扫码进入小程序「外部人员就餐」，按提示填写并提交。

  1. 选择用餐日期：默认今天，可选未来 7 天内的日期。
  2. 选择餐别：早餐 / 午餐 / 晚餐，支持多选（如同时勾选午餐和晚餐）。
  3. 填写个人信息：姓名、联系电话（可一键授权自动填充）、工作单位。
  4. 选择到访区域：提交后系统会自动通知该区域的接待管理员。
  5. 填写被访问人：即本次来访对接的公司内部同事姓名。
  6. 选择被访部门：从下拉列表中选择（下拉选项由后台统一维护）。
  7. 填写人数：默认 1 人，按实际就餐人数填写；如有需要可补充备注。
  8. 提交：提交成功后系统生成一个 6 位查询凭证码，请截图或记下保存。
提交规则：同一手机号、同一天、同一餐别只能提交一次；不同餐别可继续提交（如中午提交过午餐，还可以再提交晚餐）。如需修改已提交的餐别，请联系接待人处理。

外部人员二、查询分配结果与进入指引

  1. 进入小程序「订餐查询」页面。
  2. 可通过「我的订单」直接查看，或输入 6 位凭证码 查询（换手机也能查）。
  3. 管理端分配完成后，即可看到：用餐地点名称、地点实拍图片、如何进入的文字指引。
  4. 按指引前往指定食堂就餐即可。
分配前显示「待分配」属正常状态，请管理员分配后再来查询。小程序订阅消息开通后，分配结果还会自动推送到微信，无需手动查询。

内部管理员三、接收钉钉通知

外部人员提交订单后，钉钉机器人会以单独会话的形式，将订单推送给该区域的全部接待成员。

通知样式示例
【外部人员就餐通知 · 区域A】
· 用餐日期：2026-11-09（周一）
· 餐别：晚餐
· 申请人：张三
· 联系人电话：19900000001
· 被访部门：信息中心
· 访问人：李四
· 人数：3
收到通知即表示有外部人员订餐，需要你登录管理端为其分配用餐地点（见下一步）。通知按区域精准分发，只发给对应区域的成员。

内部管理员四、登录管理端并分配地点

  1. 浏览器打开管理端：http://10.1.4.23:48081/admin/（正式环境地址以内部通知为准），输入管理口令登录。
  2. 切换到「订餐记录」标签，可按日期 / 区域 / 餐别 / 状态筛选订单。
  3. 找到待分配的订单，点击「分配」，选择用餐地点后确认。
  4. 分配成功后：外部人员即可在查询页看到地点和进入指引；系统自动按「人数 × 地点单价」记录预计金额。
后续调整：修改人数会自动重算预计金额；取消分配会回滚金额并让订单回到待分配状态；拒绝用于特殊情况。

内部管理员五、日常管理与统计

  1. 看板：一屏查看今日已分配 / 待分配单数、预计与真实消费金额、地点与部门分布。
  2. 真实金额：就餐完成后，在订餐记录中维护该单的实际消费金额，与预计金额对比。
  3. 地点与路线：维护各食堂的人均单价、启用状态、地点图片与「如何进入」说明文字。
  4. 区域与成员：维护到访区域及各区域的钉钉通知成员（按手机号匹配）。
  5. 被访部门：维护小程序填报页的下拉选项。
  6. 导出：按当前筛选条件导出 Excel，含金额列，可直接用于费用核对。

附录常见问题

问题说明
提交后提示「已提交过」？同手机号同日同餐别不可重复提交。如需改餐别请修改为新餐别重新提交，或联系接待人。
查询页一直显示「待分配」？管理员尚未分配地点，请联系被访部门催办。
凭证码丢了怎么办？同一微信进入「我的订单」可直接查看；换手机可联系接待人代查。
钉钉没收到通知？确认你已被管理员加入对应「区域成员」列表，且钉钉资料中的手机号与管理端登记一致。
人数填错了？管理员可在管理端直接修改人数，预计金额自动重算。
